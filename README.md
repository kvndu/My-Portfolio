# Kavindu Heshan - Software Engineer Portfolio

A modern, high-performance portfolio website built with **React** and **Vite**, featuring a luxury dark obsidian theme with vibrant orange accents (`#ff5e14`), animated glassmorphism cards, interactive project modals, and tailored photo presentation.

---

## 🚀 Features

- **Exact Design Match**:
  - Dark circular hero framing with real photo portrait
  - Prominent "Software Engineer" branding in radiant orange
  - Interactive social circular buttons (GitHub, LinkedIn, LeetCode, Instagram)
  - Floating metric stats badge (`5+ Experiences`, `20+ Project done`, `80+ Happy Clients`)
  - "Hire Me" & "Download CV" action triggers with celebration confetti!
- **Interactive Photo Switcher**:
  - Toggle between **Studio Tone**, **Portrait Crop**, and **Full Photo** directly from the UI.
- **Sections Included**:
  - **Hero**: Clean intro, punchy pitch, floating badges, and quick CTAs.
  - **Services**: Full-stack web dev, backend & API architecture, database tuning, and cloud DevOps.
  - **About Me**: Career story, engineering pillars, interactive details card, and experience timeline.
  - **Technical Arsenal**: Tabbed skill matrix (Frontend, Backend, Databases, DevOps & Tools) with visual progress meters and tech ecosystem chips.
  - **Projects / Portfolio**: Filterable project gallery with live demo links, repository buttons, and architecture modals.
  - **Contact**: Working direct contact form + instant WhatsApp / Email links.
  - **Hire Me Modal**: In-depth project inquiry & full-time hiring proposal form with budget selector.
  - **Resume Modal**: Printable and downloadable resume generator.

---

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build

```bash
npm run build
```

The optimized static production bundle will be built into the `dist/` folder, ready for deployment to Vercel, Netlify, GitHub Pages, or Render.
